# Конфигурация и доступ

Сервер читает JSON один раз при запуске: `codex-vision --config /absolute/path/config.json`. Неизвестные параметры отвергаются. Без файла используются встроенные observe-настройки.

Используйте [observe-пример](../configs/config.example.json) или [macOS assist-пример](../configs/assist.macos.example.json). Личный `config.json` и `configs/*.local.json` исключены из Git.

| Параметр | Назначение |
| --- | --- |
| `mode` | `observe` для чтения; `assist` для явно разрешённого ввода |
| `allow` | Конкретные capabilities: например `window_focus`, `mouse_click`, `ui_fill` |
| `allowed_processes` | Точные полные пути executable для управления приложениями |
| `local_approval` | Локальное разрешение операций ввода; для assist-примера — true |
| `confirm_each_action` | По умолчанию true: подтверждения действий, требующих review; false использует постоянное локальное разрешение |
| `cursor_mode` | `smooth`, `fast` или `rapid`; применяется на macOS |
| `timeout_ms` | Локальный таймаут операций, 100–30000 мс |
| `max_actions_per_minute` | Предел ввода в минуту, 0–600; 0 отключает предел |
| `max_actions_per_task` | Бюджет ввода за время жизни процесса, 0–10000; 0 отключает предел |
| `stop_file` | Файл аварийной остановки |
| `audit_file` | Локальный JSONL-аудит |
| `images` | Разрешена ли выдача изображений MCP-клиенту |

Бюджеты чтения и ввода учитываются раздельно. Локальные лимиты сервера не являются лимитами подписки Codex. Отключение локальных пределов не отменяет стоимость работы модели.

## Пути и права

Задавайте абсолютные пути `stop_file` и `audit_file` либо фиксированный `cwd` в конфигурации MCP. Храните конфиг в каталоге, который контролирует оператор, с правами, исключающими его изменение недоверенными пользователями. Не добавляйте секреты в примеры и не коммитьте свой рабочий конфиг.

`allowed_processes` ограничивает ввод, а не наблюдение: видимые окна могут попадать в снимки независимо от списка. Разрешённое приложение может показывать содержимое, открытое им с диска или из сети.

Для FreeCAD добавьте оба executable:

```json
[
  "/Applications/FreeCAD.app/Contents/MacOS/FreeCAD",
  "/Applications/FreeCAD.app/Contents/Resources/bin/freecad"
]
```

Первый запускает bundle, второй обслуживает GUI. Допуск не распространяется на Python, соседние helper-программы и произвольные файлы из `Resources`.

## Подтверждения и остановка

`local_approval:true` и `confirm_each_action:false` дают постоянное разрешение на настроенные операции без отдельных диалогов. Используйте это только для доверенного клиента. В режиме подтверждения backend должен предоставлять локальный review UI; отсутствие такого UI не считается согласием.

`session_stop` необратимо блокирует ввод текущего процесса. То же происходит при появлении `stop_file`. Для нового запуска вручную устраните stop-файл и перезапустите сервер. `observation_control stop` останавливает только просмотр и не равнозначен аварийному запрету ввода.

Политика не меняется через аргументы MCP. Подробнее: [SECURITY.md](../SECURITY.md).
